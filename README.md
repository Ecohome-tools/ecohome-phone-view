# Ecohome Phone View
Plugin SketchUp xuất mô hình ra 1 file HTML 3D để xem offline trên điện thoại. Miễn phí, xem giấy phép trong LICENSE.txt.

## Tải về (luôn là bản mới nhất)
**https://github.com/ecohome-tools/ecohome-phone-view/raw/main/dist/Ecohome_PhoneView.rbz**

Cài đặt: trong SketchUp chọn Extension Manager > Install Extension, chọn file .rbz vừa tải.

- `version.json`: thông tin bản mới nhất (plugin tự kiểm tra cập nhật).
